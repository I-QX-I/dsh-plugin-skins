# 预览说明 / About the previews

首页动图录自 Windows 上运行的 DeepSeek Harness，使用 Aero 液体玻璃和中文界面。输入区近景取自同一段录屏。

动图约13.6秒，宽1080像素，以16 fps播放，WebP文件约5.2 MB。首尾用0.4秒淡化衔接，方便循环观看。帧率经过压缩，不能用于判断插件的实际运行帧率。

主题和材质设置图为同一宿主的原始截图。主题图展示九款配色的选择卡片；采集期间没有更改设置。静态首页图由用户提供。

The animation was recorded from DeepSeek Harness running on Windows, with Aero liquid glass and the Chinese interface. The input-area close-up comes from the same recording.

The looping WebP is about 13.6 seconds long, 1080 pixels wide and 5.2 MB, playing at 16 fps. A 0.4-second crossfade joins the ends. The reduced frame rate keeps the file smaller and does not represent the plugin's rendering performance.

The theme and material images are original screenshots from the same host. The theme image shows the nine palette selectors; settings were unchanged during capture. The still homepage image was supplied by the user.
