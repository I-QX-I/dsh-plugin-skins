# 安全 / Security

请从本仓库的 [Releases](https://github.com/I-QX-I/dsh-plugin-skins/releases) 下载安装包。可用 `SHA256SUMS.txt` 检查文件完整性，签名验证方法见 [制作者标记](WATERMARKS.md)。安装遵循宿主权限，由插件管理器完成；插件运行时不收集遥测数据或下载脚本。

如果发现数据泄露、路径越界或代码执行漏洞，请优先使用 GitHub 的 Private vulnerability reporting。若入口不可用，可以提交不含敏感细节的 issue，联系维护者。请勿在公开页面上传令牌、私人聊天或其他敏感信息。

Download installation packages from this repository's Releases. Check file integrity with `SHA256SUMS.txt`; signature verification is described in [Creator marks](WATERMARKS.md). Installation follows host permissions and uses the plugin manager. The runtime does not collect telemetry or download scripts.

Report vulnerabilities through GitHub private vulnerability reporting where available. Otherwise, open an issue without sensitive details to contact the maintainer. Keep tokens and private conversations out of public reports.
